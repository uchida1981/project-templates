# project-templates

## 中学受験進路相談 多視点討論システム

### 概要

`/debate` コマンドで、中学受験の進路相談を**塾講師・教育者・キャリアコンサルタント**の3視点から討論させ、最後に統合役が結論を出す仕組みです。

---

## エージェント一覧（`.claude/agents/`）

| ファイル | 役割 | 発言スタイル |
|---|---|---|
| `tutor.md` | 塾講師 | 偏差値・配点・合格可能性を数値で分析。算数重視。根拠なき励ましはしない。 |
| `educator.md` | 教育者 | 知的好奇心・自走性・長期的健全さを重視。小3偏差値の不確実性や過負荷リスクを指摘。塾講師に異議も唱える。 |
| `career-consultant.md` | キャリアコンサル | 20年後の人生・家族の消耗から逆算。「誰のための到達点か」を問う。大学付属など現実的代替案を必ず1つ提示。 |
| `integrator.md` | 統合役 | 3者の発言を公平に整理し、メリデメ・対立点を明示した上で実行可能な統合結論を出す。予定調和禁止。 |

各エージェントの発言字数：tutor・educator・career-consultant は200〜300字、integrator は400〜600字。

---

## `/debate` コマンドの使い方（`.claude/commands/debate.md`）

### 既定の前提で討論する

```
/debate
```

既定の前提（小3・5月・偏差値59.9・三鷹吉祥寺60分圏）で2ラウンド討論し、統合結論を出します。

### 前提を差し替えて討論する

```
/debate <独自の前提テキスト>
```

例：

```
/debate 小5・10月。4科偏差値62。算数65・国語58・理科63・社会60。女子。渋谷教育学園渋谷を第一志望。問い：今からの1年半で最大化するには何をすべきか。
```

### 実行フロー

```
Round 1: tutor → educator → career-consultant
Round 2: tutor → educator → career-consultant  （前ラウンドの全発言を参照）
Final:   integrator（全6発言を読んで統合結論）
→ debate_log.md に保存
```

---

## 前提の差し替え方

`/debate` の引数として自由なテキストを渡せます。以下の項目を含めると、各エージェントがより具体的に応答します：

- **学年・時期**（例：小5・10月）
- **4科偏差値と科目別内訳**
- **性別・学校タイプの希望**（男子校／女子校／共学）
- **通学圏・通学時間の制約**
- **子どもの特性**（自走型・競争好き・読書家・etc）
- **問い**（「どこを志望すべきか」「算数の強化策は」など）

---

## 出力ファイル

討論の全記録は `debate_log.md` に保存されます。実行のたびに上書きされるため、残したい場合は別名保存してください。

---

## ファイル構成

```
.claude/
  agents/
    tutor.md              # 塾講師エージェント定義
    educator.md           # 教育者エージェント定義
    career-consultant.md  # キャリアコンサルエージェント定義
    integrator.md         # 統合役エージェント定義
  commands/
    debate.md             # /debate スラッシュコマンド定義
debate_log.md             # 最新の討論ログ（自動生成）
```
