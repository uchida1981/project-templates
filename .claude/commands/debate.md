# /debate — 中学受験進路相談 多視点討論コマンド

引数として検討対象の前提を渡す。省略時は既定の前提を使用する。

**使い方:**
```
/debate                        # 既定の前提で討論
/debate <独自の前提テキスト>    # 前提を差し替えて討論
```

---

## 実行手順

以下の手順を**必ず順番通りに**実行してください。

### Step 0: 前提の設定

引数 `$ARGUMENTS` が空の場合、以下の既定の前提を使用する:

```
小3・5月時点の中学受験生。4科偏差値59.9。算数57.1（安定A）、理科67.6（平均34.7の難回でブレ大・1位）、国語53.7（前回59.2から低下しB）、社会58.8。構造理解型の自走タイプ。通学は三鷹・吉祥寺から60分以内。男子校・共学とも検討可。問い：このまま進めばどこまで伸ばせるか、どう育てるべきか。
```

`$ARGUMENTS` が指定された場合はそれを前提として使用する。

---

### Step 1: ラウンド 1

以下の順番で3つのサブエージェントを**順番に**呼ぶ（並列不可 — 各エージェントが前の発言を参照するため）:

**1-A: tutor エージェントを呼ぶ**

プロンプト:
```
以下の前提について、塾講師の立場から助言してください（200〜300字）。

【前提】
{前提テキスト}

【ラウンド】1回目
【これまでの発言】なし
```

**1-B: educator エージェントを呼ぶ**

プロンプト:
```
以下の前提と、すでに出た発言を読んだ上で、教育者の立場から助言してください（200〜300字）。必要なら塾講師の見解に異議を唱えてください。

【前提】
{前提テキスト}

【ラウンド】1回目
【tutor の発言】
{tutor の発言}
```

**1-C: career-consultant エージェントを呼ぶ**

プロンプト:
```
以下の前提と、すでに出た発言を読んだ上で、キャリアコンサルタントの立場から助言してください（200〜300字）。現実的な提案を必ず1つ含めてください。

【前提】
{前提テキスト}

【ラウンド】1回目
【tutor の発言】
{tutor の発言}

【educator の発言】
{educator の発言}
```

---

### Step 2: ラウンド 2

ラウンド1の全発言を踏まえて再度3エージェントを順番に呼ぶ:

**2-A: tutor エージェントを呼ぶ**

プロンプト:
```
ラウンド1の発言を読んだ上で、塾講師の立場から応答・深掘りしてください（200〜300字）。

【前提】
{前提テキスト}

【ラウンド】2回目
【ラウンド1の全発言】
{ラウンド1の全発言}
```

**2-B: educator エージェントを呼ぶ**

プロンプト:
```
ラウンド1の発言を読んだ上で、教育者の立場から応答・深掘りしてください（200〜300字）。

【前提】
{前提テキスト}

【ラウンド】2回目
【ラウンド1の全発言】
{ラウンド1の全発言}

【tutor のラウンド2発言】
{tutor R2 の発言}
```

**2-C: career-consultant エージェントを呼ぶ**

プロンプト:
```
ラウンド1・2の発言を読んだ上で、キャリアコンサルタントの立場から応答・深掘りしてください（200〜300字）。現実的な提案を必ず1つ含めてください。

【前提】
{前提テキスト}

【ラウンド】2回目
【ラウンド1の全発言】
{ラウンド1の全発言}

【tutor のラウンド2発言】
{tutor R2 の発言}

【educator のラウンド2発言】
{educator R2 の発言}
```

---

### Step 3: integrator による統合

全ラウンドの発言をまとめて integrator エージェントを呼ぶ:

プロンプト:
```
以下の討論全文を読み、(1)各見解のメリット・デメリットと対立点、(2)統合結論を出してください（合計400〜600字）。

【前提】
{前提テキスト}

【ラウンド1: tutor】
{tutor R1}

【ラウンド1: educator】
{educator R1}

【ラウンド1: career-consultant】
{career-consultant R1}

【ラウンド2: tutor】
{tutor R2}

【ラウンド2: educator】
{educator R2}

【ラウンド2: career-consultant】
{career-consultant R2}
```

---

### Step 4: debate_log.md に保存

以下の形式で `debate_log.md` をプロジェクトルートに書き出す:

```markdown
# 中学受験進路相談 討論ログ

**実施日時:** {現在の日時}
**前提:** {前提テキスト}

---

## ラウンド 1

### tutor（塾講師）
{tutor R1}

### educator（教育者）
{educator R1}

### career-consultant（キャリアコンサル）
{career-consultant R1}

---

## ラウンド 2

### tutor（塾講師）
{tutor R2}

### educator（教育者）
{educator R2}

### career-consultant（キャリアコンサル）
{career-consultant R2}

---

## 統合結論（integrator）

{integrator の出力}
```

保存後、討論の要点と debate_log.md のパスをユーザーに伝える。
